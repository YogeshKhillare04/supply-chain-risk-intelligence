# Dataset Setup

This project uses the **DataCo Smart Supply Chain Dataset** from Kaggle.

## Download Instructions

1. Go to: https://www.kaggle.com/datasets/shashwatwork/dataco-smart-supply-chain-for-big-data-analysis
2. Download the dataset (you'll need a Kaggle account)
3. Extract the ZIP file
4. Place `DataCoSupplyChainDataset.csv` in this folder (`data/raw/`)

## Expected File

```
data/
├── raw/
│   └── DataCoSupplyChainDataset.csv    ← Place the downloaded file here
├── processed/
│   └── (generated by notebooks)
└── README.md
```

## Dataset Overview

- **Records**: 180,519 supply chain transactions
- **Features**: 53 columns covering orders, shipping, customers, products, and financials
- **Target Variable**: `Late_delivery_risk` (binary: 1 = late, 0 = on time)
- **Time Range**: 2015–2018
- **Source**: DataCo Global (anonymized supply chain data)

## Key Columns Used

| Column | Description |
|--------|-------------|
| `Late_delivery_risk` | Target — whether delivery was late (1) or on time (0) |
| `Days for shipment (scheduled)` | Planned shipping duration in days |
| `Days for shipping (real)` | Actual shipping duration (removed — data leakage) |
| `Delivery Status` | Final delivery status (removed — data leakage) |
| `Shipping Mode` | First Class, Second Class, Standard Class, Same Day |
| `Market` | Geographic market (Africa, Europe, LATAM, Pacific Asia, USCA) |
| `Order Region` | Specific region within market |
| `Category Name` | Product category |
| `Customer Segment` | Consumer, Corporate, Home Office |
| `Sales` | Order sales value |
| `Order Item Quantity` | Number of items ordered |
| `Benefit per order` | Profit/benefit from the order |

## Note

The raw data file is not included in this repository because it's ~50MB. The processed data files generated by the notebooks are also excluded via `.gitignore`.
